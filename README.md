# Nu Corpo — Demo visual para GitHub Pages

Demo estética estática, sem PHP e sem banco.

Arquivos principais:
- index.html
- biquinis.html
- produto.html
- atacado.html
- carrinho.html
- assets/css/style.css
- assets/js/app.js
- assets/img/

Para publicar: suba o conteúdo desta pasta para a raiz do repositório e ative Settings → Pages → Deploy from a branch → main → /(root).
